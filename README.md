# رحلة العميل | Customer Journey

محرك ألعاب تسوق تفاعلية: يحوّل متجرًا إلكترونيًا إلى متجر ثلاثي الأبعاد يتجوّل فيه العميل بمنظور الشخص الأول، يقترب من المنتجات، يفتح تفاصيلها، ويضيفها إلى السلة.

## التشغيل

```bash
npm install
npm run assets      # يولّد مجسمات GLB وصور المنتجات (موجودة مسبقًا في public/)
npm run dev         # http://localhost:3000
```

الإنتاج: `npm run build && npm start`

نسخة ثابتة للعب فقط (بدون تحويل الروابط): `node scripts/build-artifact.mjs` → `dist-artifact/`

## التحكم

| الكمبيوتر | الجوال |
|---|---|
| `W A S D` أو الأسهم للمشي، `Shift` أسرع | العصا الافتراضية (يسار الأسفل)، دفعها للآخر = أسرع |
| انقر على المشهد ثم حرّك الماوس للنظر، `Esc` لتحرير الماوس | اسحب بإصبعك على المشهد للنظر |
| `E` أو النقر لعرض المنتج الذي تنظر إليه | زر «عرض المنتج» أو المس المنتج |
| `C` لفتح السلة | زر السلة أعلى الشاشة |

## البنية

```
src/pipeline/          تحويل المتجر (كل مرحلة دالة مستقلة قابلة للاختبار)
  extract/             1. الاستخراج: shopify · jsonld · salla · zid  (+ robots.txt وتصنيف الأخطاء)
  normalize.ts         2. توحيد البيانات (أسعار عربية، تكرار، صور بديلة)
  theme.ts             3. هوية المتجر (ألوان المتجر داخل نطاق دافئ مريح)
  templates.ts         4. اختيار القالب ثلاثي الأبعاد
  placement.ts         5. توزيع المنتجات على الأرفف (حتمي)
src/engine/            6. محرك الشخص الأول (R3F + Rapier) — يقرأ StoreLayout فقط
src/cart/              7. السلة (Zustand + حفظ محلي)   8. الدفع (checkout.ts)
src/ui/                الواجهات: البداية، HUD، بطاقة المنتج، السلة، العصا
src/input/ src/audio/  الإدخال بالأفعال، والصوت المولّد بالـ WebAudio
scripts/build-assets.mjs  خط إنتاج الأصول (GLB عبر glTF-Transform)
assets/                الاتجاه الفني + سجل الأصول
docs/ARCHITECTURE.md   المعمارية والمهارات
```

## ربط المتاجر الحقيقية

`POST /api/store/import { "url": "..." }` يعيد `StoreLayout` أو خطأ مصنّفًا:

| المصدر | الحالة |
|---|---|
| Shopify (`/products.json` العام) | يعمل، ويحترم robots.txt، ويولّد رابط سلة رسمي للدفع |
| أي متجر ينشر schema.org Product (JSON-LD) | يعمل |
| سلة | يتطلب OAuth من Salla Partners. يقرأ `SALLA_ACCESS_TOKEN` للتطوير فقط |
| زد | يعيد `auth_required`، والمحوّل غير مكتمل |
| متجر يمنع القراءة / بلا بيانات عامة | خطأ `blocked` / `no_products` برسالة واضحة، واللعبة تبقى قابلة للعب بالمتجر التجريبي |
