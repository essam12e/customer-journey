# رحلة العميل | Customer Journey

محرك ألعاب تسوق تفاعلية: يحوّل متجرًا إلكترونيًا إلى متجر ثلاثي الأبعاد يتجوّل فيه العميل بمنظور الشخص الأول، يقترب من المنتجات، يفتح تفاصيلها، ويضيفها إلى السلة.

## التشغيل

```bash
npm install
npm run assets      # يولّد مجسمات GLB وصور المنتجات (موجودة مسبقًا في public/)
npm run dev         # http://localhost:3000
```

الإنتاج: `npm run build && npm start`

نسخة ثابتة للعب فقط (بدون تحويل الروابط): `node scripts/build-artifact.mjs` → `dist-artifact/`

## التحكم

| الكمبيوتر | الجوال |
|---|---|
| `W A S D` أو الأسهم للمشي، `Shift` أسرع | العصا الافتراضية (يسار الأسفل)، دفعها للآخر = أسرع |
| انقر على المشهد ثم حرّك الماوس للنظر، `Esc` لتحرير الماوس | اسحب بإصبعك على المشهد للنظر |
| `E` أو النقر لعرض المنتج الذي تنظر إليه | زر «عرض المنتج» أو المس المنتج |
| `C` لفتح السلة | زر السلة أعلى الشاشة |

## ربط المتاجر الحقيقية

- واجهة اللعبة: `/?store=https://merchant.example` يحوّل المتجر ويعرضه خلف شاشة البداية (رابط قابل للمشاركة).
- `GET /api/store/import?url=…` يعيد `StoreLayout` أو خطأً مصنّفًا. أضف `&debug=1` لعرض تتبّع كل طلب (الحالة والزمن).
- `GET /api/store/probe?url=…` يعرض البيانات المنظّمة في صفحة (JSON-LD وOpen Graph وروابط sitemap) للتشخيص.
- `GET /api/image?url=…` وسيط صور (صور فقط، حد 4MB) حتى تُستخدم صور المتاجر على المجسمات.

### مسارات الاستخراج (بالترتيب)
1. **واجهات رسمية** عند وجود صلاحية التاجر: سلة (`SALLA_ACCESS_TOKEN`) وزد (المحوّل غير مكتمل).
2. **Shopify `/products.json`** العام، إذا سمح به robots.txt.
3. **زاحف عام مهذّب:** الصفحة نفسها، ثم sitemap للمتجر (الأحدث أولًا)، ثم بيانات schema.org من صفحات المنتجات
   (`Product` و`ProductGroup` وBreadcrumb للأقسام، مع Open Graph احتياطيًا).
   الحدود: robots.txt لكل رابط، 36 صفحة، 4 طلبات متزامنة، 25 ثانية.
4. **ما بعد الاستخراج:** توحيد البيانات، استنتاج الأقسام من الأسماء إن لم ينشرها المتجر، تكبير الصور المصغّرة، والمتوفر أولًا.

| المتجر | المنصة | النتيجة |
|---|---|---|
| allbirds.com | Shopify (robots يمنع `products.json`) | ✅ 17 منتجًا عبر sitemap وProductGroup |
| kith.com | Shopify | ✅ 36 منتجًا في 3 أقسام (Mens/Womens/Kids) بصورها |

| sa.almajed4oud.com | سلة | ⛔ `blocked`: حماية المتجر ترد بـ 403 على الزاحف، ولا نحاول تجاوزها |

### المتبقي
- **تطبيق سلة الرسمي (Salla Partners):** OAuth، وتخزين توكن لكل تاجر، وwebhooks لتحديث المنتجات. هذا هو الطريق الوحيد الصحيح لمتاجر سلة.
- **تطبيق زد (Zid Partners):** نفس المسار، والمحوّل الحالي يعيد `auth_required`.
- **تخزين دائم:** للمتاجر المحوّلة بدل الذاكرة المؤقتة، مع إعادة تحويل مجدولة، وحد لعدد الطلبات على `/api/store/import`.
- **الدفع الحقيقي:** Shopify عبر رابط السلة الرسمي يحتاج variant IDs، المتاحة من `products.json` فقط. سلة وزد عبر تطبيقيهما.
